# Operator's manual TM-366: operator-adjustable settings

## What the manual says about adjustable settings (transcribed pages)
The manual documents settings as on-screen Self-Test menu options, not as DIP switches.

- **Game Options, Table 2-2, p. 10:** Game Difficulty = Easy / Medium / Hard / Very Hard, factory Medium. Length of 2- or 3-Player Game = 5, 7, 10, 15 battles, factory 7.
- **Coin Options, Table 2-3, p. 11:** Free Play, Game Cost (1 to 8 coins per credit), Bonus for Quantity Buy-in.
- **Cannon award:** no cannon-count or cannon-award option appears in the Game Options or Coin Options tables, pp. 10-11.

## Negative findings
- DIP switches: none in pp. 1-17. Pages 18-25 (schematics, wiring) were not transcribed. A DIP reference there is unchecked, not ruled out.
